# SmartCampus — Complaint & Issue Tracking System

A full-stack campus complaint management system built with React, Ruby on Rails, and PostgreSQL.

## Stack
- **Frontend:** React + Vite + Tailwind CSS (in `/client`)
- **Backend:** Ruby on Rails 7 API + PostgreSQL (in `/server`)
- **Hosting:** Netlify (client) + Render (server)

## Getting Started
See `/client/README.md` and `/server/README.md` for setup instructions.

## Roles
| Role | What they can do |
|------|-----------------|
| Student | Submit complaints, track status |
| Admin | Assign, resolve, reopen all complaints |
| Staff | Resolve complaints assigned to them |
